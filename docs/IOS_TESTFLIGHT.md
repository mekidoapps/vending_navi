## Isolation and execution limits

build: fresh macos-15 runner, max 30 minutes. Flutter/CocoaPods resolution receives no
configured secrets. Compile gets only the three client runtime values intentionally
embedded in the app, never p12/profile/API key. Tool output is suppressed. The existing
runtime checker verifies syntax, OAuth pairing and built plist injection.
flutter build ipa --release --no-codesign produces the unsigned archive.

sign: a different fresh macos-15 runner, max 15 minutes. Downloads authenticated encrypted
archive and reads only pinned source helper; does not execute archive content, Flutter,
pod, Ruby or project/dependency build scripts. Receives p12/password/profile only during
export. Temporary random-password keychain locks after 900 seconds. Valid distribution
identity, Team, profile name/type/expiry, Bundle, cert fingerprint membership, and IPA
signature/entitlements/profile UUID/version/runtime-settings hashes must match.
xcodebuild -exportArchive signs/exports without automatic provisioning updates.
Finally removes p12/profile/keychain and restores original keychain search list.
Cleanup must succeed before the encrypted IPA is transferred onward.

upload: a third fresh runner, max 10 minutes. Re-verifies authenticated transfer,
IPA SHA256/signature/identity/profile/settings before materializing the ASC p8.
Only this job receives the API key. altool is invoked once with an 8-minute command
timeout, then p8 is deleted. No tester management, processing poll, App Store review
submission or public release. Accepted command does not prove tester availability.

Sequential job time limits total **55 runner minutes**, excluding queue and reviewer
waits. No automatic retry; attempt >1 skips all jobs. Workflow-wide concurrency is one.
All source checkouts are github.sha with no persisted credentials; ref/input SHA/HEAD,
run attempt, reviewed lock hash, toolchain and human confirmation are guarded.
Permissions contents:read only; pinned actions; no cache. No raw app/config/log artifact.

## Encrypted intermediate artifacts

Fresh-runner isolation requires transferring archive and IPA. To avoid exposing client
settings or binaries in this public repository, only encrypted .enc and .mac files
are uploaded, each artifact with retention 1 day. P12, profile, passwords and p8 are
never included in payloads. The owner-generated 256-bit transfer master derives
separate encryption-password and HMAC keys. AES-256-CBC/PBKDF2 (200000 iterations)
is authenticated with HMAC-SHA256 over kind + run/source/build context + ciphertext.
MAC is checked before decryption/extraction. Only regular files/directories are
extracted, with no symlinks/special files, path escape, case-insensitive duplicate,
oversize or duplicate entry. Ciphertext is still sensitive: retain the transfer key
privately and do not publish it. No encrypted artifact is created in this local task.

The build runner can access client config and the later transfer secret; those are
not protected against a malicious dependency persisting within that build runner.
Fresh signing/upload runners prevent such dependency processes from reaching signing
private keys or ASC credentials. The boundary trusts reviewed helper/pinned actions,
GitHub-hosted platform and Apple system tools; it does not promise protection from
compromised platform/toolchain itself.

# デザインシステム

## 1. コンセプト

> 地図を邪魔せず、必要な操作だけが柔らかく浮かぶUI。

- 爽やか、清潔、軽い、やさしい印象
- 白、水色、淡い青、濃すぎない青を中心にする
- 枠線を増やさず、余白、濃淡、軽い影で区切る
- 地図を主役として、情報は必要な時だけ出す
- 強い原色、濃い黒影、過度なグラデーションを避ける

## 2. テーマ方針【確定】

### MVP

- 正式テーマはスカイブルー系1種類を完成させる。
- 内部はテーマ切替可能なトークン構造にする。
- 実装終盤に負担が小さければ、パステル系4〜5種類を追加できる。

### 将来候補

- Sky Blue
- Mint
- Lavender
- Peach
- Lemon / Cream

テーマ変更は、状態の意味、エラー、警告、基本文字色を変えない。

## 3. デザイントークン

```text

```

色コードは実装モックと実機確認後に確定する。【実機調整可能】

## 4. 余白

8pxグリッドを基準とする。

| 用途 | 基準値 |
|---|---:|
| 微小間隔 | 4px |
| 最小間隔 | 8px |
| 関連要素 | 12px |
| 通常の内側余白 | 16px |
| セクション間 | 24px |
| 大きな区切り | 32px |
| 画面左右 | 16px |

数値は小型端末で調整可能。

## 5. 角丸

| 対象 | 基準値 |
|---|---:|
| タグ・商品チップ | 12px |
| 入力欄・通常ボタン | 16px |
| カード・検索パネル | 20px |
| 地図上の吹き出し | 24px |
| 丸ボタン | 完全な円 |
| ピルラベル | 高さの半分 |

全体的に大きめの角丸を採用する。【確定】

## 6. 影・境界

### 通常画面

- 影はほぼ使わないか、非常に軽くする。
- 薄い境界線と余白で区切る。

### 地図上

- 丸ボタン、検索パネル、吹き出しのみ少し強い影を使う。
- 明るい地図でも埋もれない薄い境界線を併用する。
- 黒く濃い影を避ける。

## 7. 背景と透明度

- 通常画面: 白または非常に薄い水色
- ホーム: 全面地図
- 地図上のUI: ほぼ不透明な白
- 強いガラス表現・背景ぼかしはMVPで使用しない

## 8. タイポグラフィ

日本語システムフォントを基本とする。

| 用途 | サイズ候補 | ウェイト |
|---|---:|---:|
| 画面タイトル | 20px | 600 |
| カードタイトル | 17〜18px | 600 |
| 商品名・主要情報 | 15〜16px | 500〜600 |
| 本文 | 14〜15px | 400 |
| 補足 | 12〜13px | 400 |
| ボタン | 14〜15px | 600 |

使用ウェイトは400、500、600を基本とする。

## 9. アイコン

Material Symbols Rounded系の、角が丸いシンプルなアイコンで統一する。

- 探す: 虫眼鏡
- 登録: プラス
- マイ: 人型
- 現在地: 照準
- 確認済み: チェック
- 推定: クエスチョン
- 古い情報: 時計
- 経路: 矢印または経路
- 更新: 更新矢印
- 報告: 警告

同じ意味に複数のアイコンを混在させない。

## 10. ホーム操作ボタン

```text
          探す
      登録   マイ
```

- 探す: 60px候補
- 登録・マイ: 52〜56px候補
- 間隔: 10〜12px
- 画面端: 16px以上＋Safe Area

「探す」を他の2つより大きくする。【確定】

## 11. 検索パネル

- 右側の探すボタン付近から左へ展開
- 角丸20〜24px
- 白背景
- 画面幅75〜85%以内
- 必要に応じて上方向へ候補を展開
- 選択後は閉じ、ピル型ラベルを残す

## 12. ピンと状態表現

### 確認済み

- 通常濃度の青
- 塗りつぶし
- チェック

### 推定

- 薄い水色
- 枠線中心
- `?`
- 「あるかも」

### 古い情報

- グレー寄りの青
- 時計
- 「以前の情報」

状態は色・形・アイコン・文言の複数要素で区別する。メーカー別色分けは初期必須ではなく、実画面を見て二次対応を判断する。

## 13. 吹き出し

- 角丸24px候補
- 白背景
- 軽い影
- 右上に閉じる`×`
- 最大幅320〜360px候補
- 代表商品は2〜3件
- 第一操作「ここに行く」
- 第二操作「詳細」

吹き出し中心、ピン位置、最大高は実機確認で調整する。

## 14. ボタン

### 第一ボタン

- 青系背景
- 白文字
- 高さ48〜52px
- 角丸16px

### 第二ボタン

- 白または薄い水色
- 青文字
- 薄い境界線

### テキストボタン

- キャンセル、後で、スキップ
- 主操作より目立たせない

### 危険操作

- 赤は文字・アイコン等の限定範囲
- 大面積の赤背景を避ける

## 15. アニメーション

| 動作 | 候補時間 |
|---|---:|
| 押下 | 100〜150ms |
| 検索パネル | 200〜240ms |
| 吹き出し | 180〜220ms |
| ピン選択 | 150〜200ms |

- 過度なバウンドを使わない
- 検索パネルは右から左へ自然に展開
- 吹き出しは軽いフェード＋拡大
- ピン選択時は地図移動後に吹き出しを出す

## 16. アクセシビリティ

- タップ領域は最低48px
- 状態を色だけで伝えない
- 文字サイズ変更でも主要ボタンを操作可能にする
- 長い商品名は必要に応じて2行まで許容
- `×`は見た目より広いタップ領域を持つ
- 地図ボタン、ピン、状態ラベルへセマンティックラベルを付ける

## 17. 実機調整可能な項目

- 色コード
- 丸ボタン径
- 検索パネル幅
- 影の強さ
- 吹き出し位置・大きさ
- ピンの大きさ
- 余白・角丸の細かな数値
- アニメーション時間

画面構成、主操作、状態の意味まで変える場合は仕様変更として扱う。

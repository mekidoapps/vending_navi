# P6-04 登録位置確認・調整

> 状態: 実装中
> 日付: 2026-08-11

## 目的

自販機登録開始後に、現在地を初期候補として表示しつつ、ユーザーが地図を動かして正確な登録位置を選べるようにする。

## UI

- 全面地図
- 画面中央の固定ピン
- 「地図を動かして、ピンを自販機の位置に合わせてください。」
- 現在地へ戻るボタン
- 選択座標の簡易表示
- 「この位置で次へ」

## 状態

選択位置は`MachineRegistrationController`の`RegistrationDraft.location`へ保存する。

画面を戻って再度開いた場合、同じ登録フロー中はDraftの位置を維持する。

## 位置情報拒否・取得失敗

位置情報を取得できなくても登録フローを終了させない。

日本全体を初期表示し、地図を手動で動かせば登録位置を選択できる。

## P6-04の境界

P6-04では位置画面とrouteだけを追加する。

Home「登録」からproduction routeへの接続は、次のP6-05重複候補画面が成立した時点で行う。途中フェーズで「次へ」を押してHomeへ戻る等の仮挙動を入れない。

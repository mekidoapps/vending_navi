# P6-06 登録方法選択

> 状態: 実装中
> 日付: 2026-08-11

## 目的

位置・重複候補確認後に、新規自販機の登録方法を選択する。

## 表示

- 写真から登録
- メーカーから簡単登録

写真ルートはAI完全自動に見せず、「候補は確認・修正してから登録する」と説明する。

メーカー簡単登録は、メーカー代表商品を推定情報として登録するルートであることを説明する。

## Phase 6中の扱い

Phase 6ではメーカー簡単登録を実装対象とする。

`写真から登録`は画面上の選択肢として存在させるが、Phase 7接続前は無効状態とする。
Phase 7でcallbackを接続した時点で有効化する。

## 状態遷移

メーカー簡単登録を選んだ場合:

```text
MachineRegistrationController.chooseManufacturerMethod()
→ draft.registrationMethod = manufacturer
→ step = manufacturer
```

次のP6-07でメーカー選択画面へ接続する。

## Production導線

P6-06時点ではHomeから登録フローへのproduction接続はまだ行わない。

理由は、メーカー選択・最終確認・Callable保存が未完成の状態で本番用導線だけを開通させると、ユーザー操作が途中で行き止まりになるため。

P6-07/P6-08で画面を完成させ、P6-09の保存処理まで成立した段階でHomeから一連のrouteを接続する。

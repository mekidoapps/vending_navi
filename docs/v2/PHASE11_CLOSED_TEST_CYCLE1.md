# Phase 11 Closed Test - Cycle 1

## 目的

Phase 10で機能面・回帰・実機動作を確認済みのv2 MVPについて、
実際の利用者が説明なしで操作したときの理解度とUX上の問題を確認する。

Cycle 1では新機能の要望収集を主目的としない。

主に以下を確認する。

- 検索の理解
- ホーム3ボタンの理解
- 「確認済み」「あるかも」の理解
- 自販機登録の負担
- 写真AIの補助価値
- 検索0件時の次行動
- 操作不能・クラッシュ・重大な誤動作

## テスターへの前提

できるだけ詳しい操作説明をせず、普段アプリを使う感覚で操作してもらう。

迷った場合も、すぐに正解を教えず、

- どこで迷ったか
- 何が起きると思ったか
- どの表示を見たか

を記録する。

## Cycle 1 基本タスク

### T01 ホームを見る

アプリを起動し、自由にホームを確認する。

観察ポイント:

- このアプリが何をするものか分かるか
- 「探す」「登録」「マイ」の意味が分かるか
- 最初に何を押そうとしたか
- 地図との関係が分かるか

### T02 飲み物を探す

普段飲みそうな飲み物を1つ探してもらう。

具体的な検索方法は指定しない。

観察ポイント:

- 「探す」に自然に到達するか
- 固有商品名検索を理解できるか
- ジャンル検索を理解できるか
- 「よく飲む商品」を利用するか
- 選択中の商品が分かるか
- 検索結果と地図の関係が分かるか

### T03 自販機詳細を見る

検索結果から気になる自販機を開いてもらう。

観察ポイント:

- 詳細への入り方が分かるか
- メーカー・商品情報を理解できるか
- 「確認済み」「あるかも」の意味を推測できるか
- 売り切れ表示を理解できるか

### T04 検索結果0件を体験する

結果が存在しない検索条件を試してもらう。

観察ポイント:

- 「壊れた」と感じないか
- 次に何をすればよいか分かるか
- 条件を変える / 登録する等の次行動へ進めるか

### T05 自販機を登録する

未登録の自販機を1件登録してもらう。

観察ポイント:

- 「登録」に自然に到達するか
- ログイン要求を理解できるか
- ログイン後に元の操作へ戻れることが自然か
- 位置指定が理解できるか
- 重複確認の意味が分かるか
- 登録方法の選択肢を理解できるか
- 操作量が多すぎると感じないか

### T06 メーカーから簡単登録する

メーカーが分かる自販機をメーカー選択で登録してもらう。

観察ポイント:

- メーカーから登録する意味が分かるか
- 推定商品が自動確定ではないことを理解できるか
- 最終確認画面の内容を理解できるか

### T07 写真AI登録する

可能であれば自販機写真から登録してもらう。

観察ポイント:

- 撮影操作が自然か
- AI処理中であることが分かるか
- AI候補と確定情報を混同しないか
- 候補を直せることが分かるか
- AIが役に立ったと感じるか
- AIを使うことで登録負担が減ったか

### T08 登録済み情報を更新する

既存自販機の詳細から、商品情報または売り切れ状態を更新してもらう。

観察ポイント:

- 更新入口を発見できるか
- 現在値と変更予定を区別できるか
- 変更内容を確認してから送信できるか

### T09 基本情報修正・報告を見る

詳細から基本情報修正または報告機能を確認してもらう。

観察ポイント:

- 「情報を直す」と「問題を報告する」の違いが分かるか
- 送信後の状態を理解できるか

## 自由操作

基本タスク終了後、数分自由に操作してもらう。

以下があれば記録する。

- 押せると思ったのに押せなかった
- 戻り方が分からなかった
- 意味が分からない文言
- 表示が邪魔
- 反応が遅いと感じた
- 想定外の画面へ移動した
- 同じ操作を繰り返してしまった
- アプリを閉じたくなった箇所

## フィードバック記録

1件につき以下の形式で記録する。

### Issue ID

`P11-C1-XXX`

### 発生箇所

画面・操作:

### 起きたこと

### テスターが期待していたこと

### 再現手順

### 再現性

- 常に
- ときどき
- 1回のみ

### 影響

- 操作不能
- 操作は可能だが大きく迷う
- 少し迷う
- 見た目・表現
- 要望

### Severity

- P0
- P1
- P2
- P3
- 判定待ち

### 備考

スクリーンショット等があれば添付する。

## Severity基準

### P0

- アプリが起動できない
- クラッシュや重大なデータ破壊
- 重大なセキュリティ問題
- MVPの中心導線が広範囲に利用不能

Cycle 1中でも即時対応対象。

### P1

- MVP主要操作を正常完了できない
- 登録・検索・更新等の主要機能が実質利用不能
- 回避困難な重大UX問題

Phase 11内で必須修正。

### P2

- 操作自体は可能だが分かりにくい
- 複数テスターが同じ場所で迷う
- 誤操作を誘発する
- 表示崩れ等、品質への影響が明確

複数人が迷うUXはPhase 11で修正対象とする。

### P3

- 軽微な改善
- 好みの範囲
- MVP外の追加機能
- 将来要望

原則バックログへ送る。

## Cycle 1 修正方針

- P0: 必須修正
- P1: 必須修正
- P2: 複数人が同じ箇所で迷う場合は修正
- P3: 原則Phase 11では実装しない
- MVP外機能は追加しない

1つの修正は1つの目的に限定する。

## Cycle 1 完了条件

- 複数人による主要UX確認を実施
- 全フィードバックをP0-P3へ分類
- P0/P1を洗い出す
- 複数人が迷ったUXを特定
- Cycle 1修正対象を確定

Cycle 1完了後、必要な修正と回帰を行い、
Cycle 2で異なる端末を含むリリース候補判定へ進む。

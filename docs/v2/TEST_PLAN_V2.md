# テスト計画

## 1. テスト順序

```text
単体
→ ViewModel
→ Widget
→ Firebase Emulator結合
→ 実機機能
→ シナリオ
→ 回帰
→ クローズドテスト
```

各機能は実装直後に該当テストまで終え、最後にまとめて品質確認しない。

## 2. 単体テスト

### 商品検索

- Product ID一致
- 無効商品除外
- 売り切れ判定
- 確認済み／推定判定
- 同一自販機重複排除
- ジャンルからProduct ID展開
- 旧更新日時欠損でもクラッシュしない

### 検索順位【暫定】

1. 新しい確認済み
2. 古い確認済み
3. メーカー推定
4. 同一グループ内は距離順

売り切れの除外・順位低下はPoC後に確定する。

### 位置・重複

- 距離計算
- geohash候補後の実距離絞り込み
- 境界値
- 不正座標
- 同じ施設の複数台
- 近距離同メーカー／別メーカー／不明メーカー

### evidenceType

- manual/photoを確認済み表示
- manufacturerを推定表示
- AI未確認候補を公開へ変換しない
- 推定→確認済み
- 確認済み→推定への格下げ防止

### 商品更新

- 追加
- 無効化
- 売り切れ設定・解除
- 重複追加防止
- AI未検出による自動削除禁止
- 更新日時・revision・index同期
- 報告のみでは更新日時不変

### AI応答変換

- Manufacturer ID変換
- Product ID変換
- マスタ外候補
- 重複候補
- 空応答
- 不完全JSON
- タイムアウト
- 生レスポンス非保存

### 旧データ

- schemaVersion 1 / 2 / 欠損
- 旧`drinks` / `slots`
- Product ID変換可能／不能
- Timestamp / GeoPoint欠損
- 読み込みによる書き換えなし

### Functions検証

- 未ログイン
- App Checkなし
- restricted / suspended
- 不正ID
- 過剰件数
- 不正座標
- クライアント指定のサーバー値拒否
- requestId二重処理防止

## 3. ViewModelテスト

### ホーム

- 初期→位置取得→周辺表示
- 位置拒否・取得失敗
- 検索パネル開閉
- 商品選択→パネル閉じる
- 検索解除
- ピン選択・解除
- 別ピンへ切替
- 0件
- Repository失敗・再試行

### 詳細

- 写真あり／なし
- 検索対象優先
- 確認済み／推定分離
- 非公開化
- 更新後再取得

### 登録

- 位置保持
- 戻る操作
- 一時写真保持
- AI失敗後のルート変更
- ログイン後復帰
- 保存失敗時の下書き保持
- 送信中二重操作禁止
- 完了・中止時の破棄

## 4. Widgetテスト

### ホーム

- 上部ラベル
- 右下3ボタン
- 探すが大きい
- Safe Area
- 左へ開くパネル
- 選択中ラベル
- 長い商品名
- 大きな文字

Google MapはFake Widgetへ差し替える。

### 吹き出し

- 選択時のみ表示
- 固定位置
- 最大商品件数
- 確認済み／推定
- 閉じる
- 経路・詳細
- 小画面で全画面を覆わない

### 詳細

- 写真条件表示
- 第一・第二ボタン
- 検索対象優先
- 推定表現
- 報告導線

### 登録

- 中央固定ピン
- 権限拒否代替
- 重複候補の有無
- 撮影案内・権限・撮り直し
- AI候補編集
- AI失敗時の代替導線
- メーカー不明
- 推定説明
- 最終確認

### 更新

- 4種類の更新入口
- 商品追加・無効化
- 売り切れ
- 推定→確認済み
- 差分確認

## 5. Firebase Emulator結合テスト

### Auth / Rules

- 未ログイン公開読取
- 未ログイン書込拒否
- 自販機直接書込拒否
- 自分のfavoriteのみread/write
- 他人のuser拒否
- hidden自販機・revision・report拒否
- index直接書込拒否

### Functions

- 登録でmachine/product/photo/revision/index作成
- メーカー推定
- メーカー不明
- 不正ID拒否
- requestId冪等
- 中途失敗時の不整合防止
- 商品更新とindex同期
- reportは自動非表示にしない

### Storage

- 本人のみ一時アップロード
- 他人の読取拒否
- 非画像・サイズ超過拒否
- 正式保存関連付け
- 期限切れ削除

## 7. 実機条件

### 端末

- Pixel 6aを基準
- 小型Android
- 大型Android
- 大きな文字サイズ
- OSダークモード時もライトUIが崩れないこと

### 写真

- 日中、日陰、夜間
- 反射、手ぶれ、ピンぼけ
- 斜め、一部欠け
- 商品名が小さい
- 複数台
- ラッピング自販機

### 位置

- 高精度・低精度
- 屋内
- 拒否・今回のみ
- GPS無効
- タイムアウト
- 設定変更後復帰

### 通信

- Wi-Fi、モバイル、低速
- AI中断
- 保存中断
- バックグラウンド・再開
- Functionsタイムアウト

## 8. Golden Test候補

- 丸ボタン群
- 検索パネル
- 吹き出し
- 状態ラベル
- メーカー選択カード
- AI候補カード

地図・写真等の変動要素を含めない。

## 9. 固定テストデータ

- 確認済み・写真あり・新しい
- 推定のみ・写真なし
- 確認済み・古い
- メーカー不明・商品なし
- hidden
- 重複候補
- 同一ジャンルの複数商品
- 長い商品名
- 無効商品
- 旧名称から変換可能／不能

## 10. 重要度

- P0: データ破損、重大権限漏れ、起動不能
- P1: 主要フロー不能、クラッシュ、誤確度保存
- P2: 一部条件で操作困難、誤解を招く表示
- P3: 軽微な余白、アニメーション、文言

複数ユーザーが操作方法を理解できない場合、見た目の問題ではなくP2以上のUX不具合とする。

## 11. AI評価

実写真30〜50枚程度で評価する暫定目標:

- メーカー候補正解率: 80%以上
- 主要商品のうち1件以上が候補: 70%以上
- 誤候補を削除できる: 100%
- 未確認候補の公開保存: 0件
- 失敗後の代替登録: 100%

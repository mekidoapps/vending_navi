# ユーザーフロー

## 共通原則

- 閲覧・検索は未ログインでも利用できる。
- 登録・更新・報告・フィードバック送信時にログインを求める。
- ログイン後は、可能な限り中断した操作へ戻す。
- AI失敗時も登録フローを終了させず、別ルートを提示する。
- 保存前に内容確認画面を置く。

## F-01 周辺の自販機を見る

```text
アプリ起動
→ 位置情報確認
→ 現在地周辺の自販機を地図表示
→ ピンをタップ
→ 選択ピンを画面中央より少し下へ移動
→ 固定位置に吹き出し表示
→ 詳細 または ここに行く
```

### 例外

- 位置情報拒否: 地図の任意地点を閲覧できる。設定案内を表示する。
- 現在地取得失敗: 最後の表示位置または既定位置を表示し、再試行を提示する。
- 周辺0件: 登録導線と検索条件変更を提示する。

## F-02 固有商品を探す

```text
ホーム
→ 探す
→ 商品名を入力
→ Product IDを持つ候補を選択
→ 検索パネルが閉じる
→ 選択中ラベルを表示
→ machine_product_indexで周辺検索
→ 確認済み・推定ピンを表示
→ ピン→吹き出し→詳細
```

### 解除

```text
選択中ラベルの×
→ 検索条件を解除
→ 通常の周辺自販機表示へ戻る
```

## F-03 ジャンルから探す

```text
ホーム
→ 探す
→ ジャンルを選択
→ ジャンルに属するProduct IDを取得
→ 対応する周辺自販機を検索
→ 自販機単位で重複排除
→ 地図表示
```

## F-04 よく飲む商品から探す

```text
マイ または 検索パネル
→ よく飲む商品を登録
→ ホームの検索パネルに表示
→ 商品をタップ
→ 固有商品検索を実行
```

## F-05 自販機詳細を見る

```text
吹き出しの詳細
→ 写真（ある場合）
→ 名前・メーカー・距離・最終更新
→ 検索対象商品の状態
→ ここに行く
→ 確認済み商品
→ 推定商品
→ 場所情報
→ 情報更新・写真追加・報告
```

## F-06 メーカーから簡単登録

```text
ホームの登録
→ ログイン確認
→ 現在地取得
→ 中央固定ピンで位置調整
→ 重複候補確認
→ 登録方法選択
→ メーカーから簡単登録
→ メーカー選択
→ Functionsが代表商品を取得
→ 「あるかも」として内容確認
→ 任意で実物商品を手動追加
→ 最終確認
→ createVendingMachine
→ 自販機詳細
```

### メーカー不明

```text
メーカー選択で「分からない」
→ 推定商品なし
→ 位置のみ登録
```

## F-07 写真から登録

```text
ホームの登録
→ ログイン確認
→ 位置調整
→ 重複候補確認
→ 写真から登録
→ 安全・撮影品質の案内
→ カメラ撮影
→ 写真確認
→ 一時Storageへアップロード
→ recognizeVendingMachinePhoto
→ メーカー・商品候補を表示
→ ユーザーが削除・変更・追加
→ 最終確認
→ createVendingMachine
→ 正式写真と確認済み商品を保存
→ 自販機詳細
```

## F-08 AI失敗後に登録する

```text
AI認識失敗または候補なし
→ 撮り直す
  または メーカーから登録
  または 商品を手動追加
  または メーカー・位置だけ登録
→ 最終確認
→ 保存
```

AI失敗時も、位置や写真確認前の入力を不必要に失わない。

## F-09 重複候補を処理する

```text
位置確定
→ 近距離候補を検索
→ 候補がある場合だけパネル表示
→ 既存自販機の詳細を見る
  または 既存情報を更新する
  または 別の自販機として登録を続ける
```

隣接して複数台設置される場合があるため、候補があるだけで新規登録を禁止しない。

## F-10 商品情報を手動更新する

```text
自販機詳細
→ 情報を更新する
→ ログイン確認
→ 手動商品更新
→ 商品追加 / なくなった / 売り切れ / 売り切れ解除
→ 推定商品を「置いてあった」で確認済みに変更
→ 差分確認
→ updateVendingMachineProducts
→ 詳細再取得
```

## F-11 写真から一括更新する

```text
自販機詳細
→ 情報を更新する
→ 写真から一括更新
→ 撮影・AI認識
→ 現在情報と候補を比較
→ 追加・変更候補をユーザー確認
→ 差分確認
→ 更新
```

写真に写らなかった既存商品は自動削除しない。

## F-12 基本情報の修正を提案する

```text
自販機詳細
→ 情報を更新する
→ 基本情報修正
→ 名前 / メーカー / 位置 / 場所メモ / 屋内外を入力
→ 内容確認
→ submitMachineCorrection
→ 受付完了
```

位置・メーカー等の影響が大きい項目は、一般ユーザーによる即時上書きではなく提案として扱う。

## F-13 状態・不適切情報を報告する

```text
自販機詳細
→ 報告
→ 撤去 / 重複 / 利用不可 / 写真 / 文章 / その他
→ 任意の補足
→ 内容確認
→ submitMachineReport
→ 受付完了
```

報告1件のみで自販機を自動非表示にしない。

## F-14 フィードバックを送る

```text
マイ
→ フィードバック送信
→ 種別・本文・任意情報
→ submitFeedback
→ 送信完了
```

フィードバック内容は一般ユーザーから読み取れない。
